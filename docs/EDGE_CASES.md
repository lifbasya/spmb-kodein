# Edge Cases

## Application

- Cannot submit if required fields incomplete
- Cannot submit without documents
- Cannot edit after accepted (optional rule)

---

## Documents

- Invalid file type
- File too large
- Upload failed

---

## Verification

- Cannot verify if status != SUBMITTED
- Cannot decide if not VERIFIED

---

## Auth

- Unauthorized access
- Expired session

---

## System

- Empty data
- Network failure
- Duplicate submission
